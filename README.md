# Modern Developer Portfolio — Shivam Anand

A modern, responsive personal portfolio website built with **React.js**, **Vite**, and clean modern CSS styling.

![Portfolio Preview](./public/profile.png)

## 🚀 Live Demo & Tech Stack

- **Framework**: [React.js](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS with modern Glassmorphism, 3D Parallax Tilt, and Responsive Design
- **Icons**: Lucide Icons & Custom SVGs
- **Deployment**: Ready for [Vercel](https://vercel.com/), [Netlify](https://netlify.com/), or [GitHub Pages](https://pages.github.com/)

---

## ✨ Features

- **Hero Section**: Purple glassmorphism 3D tilt card with interactive mouse-tracking parallax and specular glare overlay.
- **Showcase Projects**: Highlighting the **ESP32-based Smart Door Unlocking System** with detailed modal view and technology breakdown.
- **Infinite Loop Marquee**: Continuous ticker strip showcasing skills and core technologies (pauses on hover).
- **Skills Matrix**: Categorized skills covering C/C++, JavaScript, ESP32 Microcontrollers, Embedded Systems, and Databases.
- **Academic Foundations**: Details for **LOVELY PROFESSIONAL UNIVERSITY** (B.Tech CSE) and **DAV PUBLIC SCHOOL, dhanupara**.
- **Contact & Social Channels**: Direct links to GitHub, LinkedIn, and email copy action.
- **Minimal Cursor Follower**: Smooth mouse-following dot effect.

## 🛠️ Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone <YOUR_GITHUB_REPO_URL>
   cd "portfolio ensite"
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

## 🌐 Deploy to Make it Live

### Option 1: Vercel (Recommended - 1 Click)
1. Go to [vercel.com](https://vercel.com/) and log in with your GitHub account.
2. Click **"Add New..."** -> **"Project"**.
3. Import your GitHub repository.
4. Click **Deploy**. Vercel will automatically build and assign a live URL (e.g. `your-portfolio.vercel.app`).

### Option 2: Netlify
1. Go to [netlify.com](https://netlify.com/) and log in.
2. Click **"Add new site"** -> **"Import an existing project"**.
3. Connect your GitHub repository and click **Deploy site**.
